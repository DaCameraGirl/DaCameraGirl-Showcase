# DaCameraGirl Showcase

A one-page home for six live projects by Angela Hudson. Built for friends and family to browse, understand, and try the projects quickly.

## Projects

- [Spades Online](https://spades-online.onrender.com/)
- [Music Mash Lab](https://music-mash-lab.onrender.com/)
- [Haunt City](https://dacameragirl.github.io/haunt-city-halloween-heat/)
- [GLB Factory](https://dacameragirl.github.io/GLB_FACTORY/)
- [Bettin2Win](https://dacameragirl.github.io/Bettin2Win/)
- [Compass Ultra](https://www.compassultra.com/)

## Run locally

Open `index.html` in a browser, or serve the folder with `python3 -m http.server 8000` and visit `http://localhost:8000`. This is a dependency-free static site.

The artwork in each card is an original typographic preview rather than a captured app screenshot. The project buttons lead to the live experiences.

## Deploy

Import this repository into Vercel as an **Other** framework project. Leave the build command blank and set the output directory to `.`. Deploy the `main` branch.

The showcase is independent of the featured projects. No code from their repositories is included here.
